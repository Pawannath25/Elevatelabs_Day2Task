# Elevatelabs_Day2Task
Sales Dashboard Creation
📊 Dataset Overview
Two main tables were used to build this dashboard:

Orders Table

Columns: OrderID, OrderDate, CustomerName, State, City

Details Table

Columns: OrderID, Amount, Profit, Quantity, Category, Subcategory, PaymentMode

A calculated column was added:
AOV (Average Order Value) = Amount / Quantity

📈 Dashboard Features
🔢 Four Summary Cards:

Total Sales (Sum of Amount)

Total Profit

Total Quantity

Average Order Value (AOV)

🥧 Pie & Donut Charts:

Quantity by Payment Mode (Donut Chart)

Quantity by Category (Pie Chart)

📊 Bar & Column Charts:

Profit by Sub-Category (Stacked Bar Chart)

Profit by Month (Column Chart)

Sales Amount by Customer Name (Bar Chart)

Sales Amount by State (Column Chart)

Slicers/Filters:

By Quarter

By State

 Purpose
The goal of this dashboard is to provide clear insights into customer buying behavior, profit trends, and sales performance across different regions, time periods, and product categories.
